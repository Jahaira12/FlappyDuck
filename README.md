# FlappyDuck
🐥 
FlappyDuck is a 2D mobile game made in unity inspired by Flappy Bird, where players guide a determined little duck through endless obstacles by tapping to stay airborne. The goal is simple: avoid the pipes, survive as long as possible, and beat your high score..
